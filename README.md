# 照片快传助手

手机相册扫码传照片到电脑文件夹的公共服务。

## 功能

- 电脑端打开页面，自动创建会话并展示二维码
- 手机扫码 → 授权 → 选照片上传
- 电脑端实时接收照片并保存到本地文件夹
- 会话 10 分钟无活动自动过期

## 路由

| 路径 | 页面 | 说明 |
|---|---|---|
| `/` | 电脑端首页 | 展示二维码与会话码，接收照片 |
| `/m/:code` | 手机端 | 扫码后打开，选照片上传 |

## 技术栈

- **前端**: React + Vite + Tailwind CSS
- **后端**: NestJS
- **文件上传**: 云存储
- **实时同步**: 短轮询（2s 间隔）

## 快速开始

```bash
npm install
npm run dev
```

## 环境变量

复制 `.env.example` 并按需配置（如存在）。
